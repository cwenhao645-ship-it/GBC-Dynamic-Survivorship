# Historical analyses — not current BMC submission results

These files preserve older source code and Git history. They are not called by the current Phase 3/3B workflow and are not current manuscript analyses.

- R/05_standardization: high-dimensional measured-covariate adjustment and complex support cells.
- R/06_models: Model A/B/C development; only isolated mathematical kernels are reused by the current code.
- R/07_validation and R/08_updating: historical temporal validation and baseline-hazard updating.
- R/10_figures/final_figures.R: old JNO main/supplement display layer, including obsolete analytical tracks and the old Figure 3.
- python/publication_tables.py: old 14-predecessor-matrix to 11-eTable assembler, not a current S1–S9 assembler.

Paths inside preserved sources refer to their historical private layout. Moving a source here is archival organization, not a validated relocation of its old pipeline. Do not run legacy entry points as part of the current submission analysis or infer scientific inclusion from their presence.
