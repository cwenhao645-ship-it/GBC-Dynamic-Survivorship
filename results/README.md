# Generated results are private inputs/outputs

This code-only repository does not distribute patient tables, fitted models, bootstrap objects or aggregate result workbooks. No frozen analysis result is altered by the repository update.

Current authorized runs produce separate Phase 2, Phase 3 and Phase 3B outputs. Phase 3 results contain Adjusted_Pathology, Unified_Cohort and Surgery_Code_Audit; Phase 3B results contain PH_Diagnostics, Model_Comparison and Bootstrap_QC. Their readers must receive real frozen workbooks, not hardcoded replacement estimates.

Future sharing of any aggregate table requires author review of reuse permission and small-cell disclosure. The code license does not license SEER data. Read docs/reproducibility_notes.md before planning a rerun or claiming complete reproducibility.
